NewzDeck v3.6.37
Operation Progress & Activity Feedback

NewzDeck is a free and open-source Windows Usenet newsreader, downloader,
and personal media automation application.

WHAT'S NEW IN v3.6.37

- Adds clear working indicators to user actions that can take noticeable time without
  changing their underlying API or processing behavior.
- Fixes Automation item Scan files so the button actually clicked shows Scanning files
  and an inline status while the library reconciliation runs.
- Adds consistent busy states to item metadata refresh/remove, Automation settings
  saves and media adds, Settings save/restore/cache cleanup, Diagnostics refresh/clear,
  and provider save/delete.
- Keeps existing true progress surfaces intact, including Manual Import percentage
  progress, full-group search progress, Discover/loading skeletons, and Update Center.
- Repairs the stale v3.6.35 sidebar/About label that remained in the v3.6.36 shell and
  adds a publishing guard that visible version identity must match the release.

Normal installed updates preserve settings, provider configuration, Automation data,
history, queue state, and user data.
