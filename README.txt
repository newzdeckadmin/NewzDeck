NewzDeck v3.7.5 - Related Media Grouping Reliability

NewzDeck is a free and open-source Windows Usenet newsreader, downloader, and personal media automation application.

v3.7.5 fixes Related Media set classification for common sequenced image/video naming formats and stabilizes Continuous-browse promotion with article-key identity.

The three-member set threshold remains unchanged. Set identity remains isolated by newsgroup, media kind, normalized base, and poster identity.

The v3.7.4 runtime baseline is otherwise preserved: private SABnzbd 5.1.2, SABCTools 9.6.3, Direct Unpack/post-processing, PAR2/repair, Automation, Smart Import, Backup & Restore, all themes, and the managed About & Updates lifecycle.
