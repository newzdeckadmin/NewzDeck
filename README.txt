NewzDeck v3.7.6 - Resizable Newsgroups Pane

NewzDeck is a free and open-source Windows Usenet newsreader, downloader, and personal media automation application.

v3.7.6 adds a draggable splitter between Newsgroups and Articles so long newsgroup names can be given more horizontal space. The selected width is remembered locally, clamps responsively, supports keyboard resizing, and can be reset by double-clicking the divider.

Newsgroup loading/search/sorting, v3.7.5 Related Media grouping, NNTP behavior, private SABnzbd 5.1.2, SABCTools 9.6.3, Direct Unpack/post-processing, PAR2/repair, Automation, Smart Import, Backup & Restore, themes, and the managed updater are preserved.
