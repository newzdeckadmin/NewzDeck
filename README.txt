NewzDeck v3.7.7 - Newsgroups Splitter Cascade Hotfix

NewzDeck is a free and open-source Windows Usenet newsreader, downloader, and personal media automation application.

v3.7.7 fixes the v3.7.6 Newsgroups divider placement and resizing issue by making the splitter and variable workspace track authoritative in the final CSS cascade.

The v3.7.6 splitter behavior and v3.7.5 Related Media grouping remain unchanged. NNTP, SABnzbd 5.1.2, SABCTools 9.6.3, Automation, Smart Import, Backup & Restore, themes and the managed updater are preserved.
