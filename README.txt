NewzDeck v3.7.3 - Managed In-App Update Handoff Hotfix

NewzDeck is a free and open-source Windows Usenet newsreader, downloader, and personal media automation application.

v3.7.3 restores the seamless About & Updates lifecycle: the verified Setup package closes NewzDeck, closes/waits for the tray, stops/waits for the Windows background service, installs the update, restores the service/tray state, and reopens NewzDeck automatically.

The old copied/renamed Picker update coordinator remains retired for Defender compatibility. Setup itself owns the managed transaction.

The v3.7.2 SABCTools 9.6.3 decoder architecture, private SABnzbd 5.1.2 integration, Direct Unpack/post-processing, Automation, Smart Import, Newsgroup Browser, Backup & Restore, and all twelve themes are preserved.
