NewzDeck v3.6.35
Manual Import Live Progress

NewzDeck is a free and open-source Windows Usenet newsreader, downloader,
and personal media automation application.

WHAT'S NEW IN v3.6.35

- Adds a real live progress bar to the Manual Media Import flow introduced in v3.6.34.
- Shows the current import phase and file while Import & Organize is running.
- Uses actual Smart Import transaction progress, including byte-based advancement when
  files are copied across drives/volumes instead of a simulated timer.
- Keeps the Import Media window open and safely locks its controls while an import is
  active, then reports files organized and Wanted targets satisfied at completion.
- Shows 100% only after authoritative library state and Wanted reconciliation finish.
- Preserves v3.6.34 Manual Import behavior, v3.6.32 no-downgrade/target-integrity
  protections, and the accepted v3.6.28-v3.6.33 compatibility stack.

Normal installed updates preserve settings, provider configuration, Automation data,
history, queue state, and user data.
