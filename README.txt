NewzDeck v3.7.4 - Release Hygiene & Publisher Reliability Maintenance

NewzDeck is a free and open-source Windows Usenet newsreader, downloader, and personal media automation application.

v3.7.4 is a stability-first maintenance release. It synchronizes remaining current-version fallback text in the app shell and tray helper, makes SABCTools/yEnc integration wording version-neutral, and corrects guarded publisher verification for GitHub Pages and annotated release tags.

The v3.7.3 managed About & Updates Setup lifecycle is preserved unchanged. The old copied/renamed Picker update coordinator remains retired.

Private SABnzbd 5.1.2, SABCTools 9.6.3, Direct Unpack/post-processing, PAR2/repair, Automation, Smart Import, Newsgroup Browser, Backup & Restore, and all twelve themes are preserved.
