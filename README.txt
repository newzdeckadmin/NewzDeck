NewzDeck v3.6.34
Manual Media Import & Wanted Reconciliation

NewzDeck is a free and open-source Windows Usenet newsreader, downloader,
and personal media automation application.

WHAT'S NEW IN v3.6.34

- Adds Manual Media Import for TV seasons or individual episodes directly from an
  Automation library item.
- Lets you choose an external source folder and Preview Import before anything is
  moved, showing episode mapping, canonical destination naming, quality decisions,
  and whether the selected profile cutoff will be satisfied.
- Commits through the existing transactional Smart Import rename/move path and
  re-checks the physical destination immediately before replacement.
- Immediately reconciles library quality and Wanted state after a successful import,
  so externally obtained media that meets the cutoff no longer remains Wanted.
- Preserves v3.6.33 TV-edition search compatibility, v3.6.32 no-downgrade/target
  integrity protections, and the accepted v3.6.28-v3.6.31 SAB/download-control stack.

Normal installed updates preserve settings, provider configuration, Automation data,
history, queue state, and user data.
