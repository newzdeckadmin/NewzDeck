NewzDeck v3.5.33 portable validation

1. Close every NewzDeck desktop window.
2. Keep the Windows Background Service stopped if that is your normal setup.
3. Extract this ZIP into a NEW folder; do not merge it into v3.5.32.
4. Run NewzDeck.exe.
5. On this fresh folder, approve the one-time prompt to download the official
   CPython 3.12.10 private runtime. This is the first important v3.5.33 test.
6. Confirm NewzDeck opens as v3.5.33 and your existing user data/settings appear.
7. Close the app, wait about 10 seconds, and launch it again. The second launch
   should retain the near-instant v3.5.32 startup behavior.
8. Test Choose Folder once. It now uses the newly source-built native picker.

Do not install/publish v3.5.33 yet. This portable is the Windows acceptance build
for the new source-complete helper set.
