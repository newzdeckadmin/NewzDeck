# NewzDeck v3.5.35

v3.5.35 is the current stable Windows production release.

It carries forward the reliability improvements developed during the v3.5.34 candidate and adds the installer/tray corrections required for a normal installed upgrade.

## User-visible improvements

- reliable installed upgrades without requiring users to manually close `NewzDeckTray.exe`;
- repaired tray right-click menu and Exit behavior;
- corrected Windows installer path handling;
- improved updater compatibility;
- safer sleep/resume lifecycle handling;
- order-safe Downloads polling;
- Completed history sorted newest first, including older history migration;
- corrected TMDB attribution display;
- localhost request hardening and cleaner user-facing errors;
- fairer Watch Folder processing.

The proven Download Engine v2/private SAB transfer behavior remains unchanged.
