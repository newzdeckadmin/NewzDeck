# NewzDeck v3.5.32 Source Status

Release: **NewzDeck v3.5.32 — Desktop Startup Performance & Fast Handoff**

This directory records the source-publication status of the already-published v3.5.32 Windows release.

The Python/JavaScript application source and exact v3.5.32 outer launcher source are present in `src/` and hashed in `SOURCE_MANIFEST.sha256`.

The v3.5.32 package also contains legacy NewzDeck-owned helper executables whose reconstructable source was not retained in the public/source workspace when those binaries were originally built. They are listed in `docs/SOURCE_RELEASES.md`.

Therefore v3.5.32 is the **licensing/source-publication transition release**, not the project's first complete corresponding-source GPL binary release.
