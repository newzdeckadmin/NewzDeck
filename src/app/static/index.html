Background Service

Keep NewzDeck downloads and future TV/movie automation running even when the main window is closed.

Checking background service…NewzDeck is checking Windows Service status.
CHECKING
System TrayThe tray icon gives you quick status and download controls while the main window is closed.
Service-owned downloadsOnce enabled, the Windows service owns the download queue. Closing NewzDeck or exiting the tray icon will not stop active downloads. Interactive folder pickers are handled by NewzDeck's native Windows picker in your signed-in desktop session.
One-time permissionWindows will show a UAC prompt when you install or repair the service. Existing provider passwords are migrated locally to machine-scoped Windows DPAPI so the background service can use them without storing plaintext credentials.

High Throughput EngineNZB downloads use warm NNTP connections, adaptive multi-article BODY pipelining, native yEnc decoding, and a RAM-backed direct-write cache to keep fast connections saturated. Provider Articles/request defaults to Auto and can be tuned from 1–10 in NNTP Providers.
