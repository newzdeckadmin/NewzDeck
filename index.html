FAQ

A few things to know before you start.

Does NewzDeck include Usenet access?

No. NewzDeck is a client application. You provide your own Usenet provider account and server credentials.

Do I need an indexer?

Direct newsgroup browsing works with your Usenet provider. Automation and interactive NZB search are designed to work with configured Newznab-compatible indexers.

Can downloads continue when I close the window?

Yes. NewzDeck includes a Windows background runtime and tray experience so active work can continue without keeping the main interface open.

Is NewzDeck signed?

No. Current Windows builds are intentionally unsigned, so Windows may display an Unknown Publisher or SmartScreen warning. Release checksums are provided on GitHub for verification.

Is NewzDeck free?

Yes. NewzDeck is a free project with source published under GNU GPLv3. There is no NewzDeck subscription fee.

Is the project still in development?

Yes. NewzDeck is under active development, and current Windows releases are built from the public source in this repository.
