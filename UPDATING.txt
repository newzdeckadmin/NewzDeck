NewzDeck v3.6.63
Name Resolution Render Coalescing & Thumbnail Trace Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.63 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.63 is a narrow Newsgroup Browser responsiveness/observability release. It coalesces redundant All Posts name-resolution renders and adds client/server thumbnail trace telemetry plus failure classification. It does not redesign Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation, Discover, provider connection budgets, or the proven 800-header strategy.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.63 Portable ZIP to a fresh folder. User data remains outside the application directory.
