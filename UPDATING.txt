NewzDeck v3.6.69
Settings Save Contention Recovery & Reliability Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.69 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.69 is a narrow Windows settings reliability release. It keeps the existing atomic settings replacement design but retries transient WinError 5/32/33 contention for up to three seconds and exposes passive recovery counters. It does not retune Images, Videos, All Posts browsing, provider allocation, Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation or Discover.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.69 Portable ZIP to a fresh folder. User data remains outside the application directory.
