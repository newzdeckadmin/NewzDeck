Updating

INSTALLED NEWZDECK
------------------
Use NewzDeck > About & Updates > Install Update.

For an in-app update, v3.6.12 Setup is the authoritative lifecycle owner:
  1. Capture whether the background service and tray are present/running.
  2. Close the browser-hosted NewzDeck app window from the signed-in Setup session.
  3. Stop the tray.
  4. Stop the background service.
  5. Replace NewzDeck program files.
  6. Run a second app-window close with the newly installed helper as a safety net.
  7. Repair and START the existing background service.
  8. Restore the tray.
  9. Finish Setup.
 10. Relaunch NewzDeck automatically.

Portable users should close NewzDeck and extract the new Portable ZIP to a
fresh folder.

Existing settings, provider configuration, Automation data, history, queue
state, and user data remain stored outside the program directory.
