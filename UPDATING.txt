NewzDeck v3.7.3 update notes

v3.7.3 restores the managed About & Updates handoff. When you choose the verified in-app update, NewzDeck now closes the browser-hosted app window before file overlay, closes/waits for the tray, stops/waits for the background service, installs the update, restores the service/tray state, and reopens NewzDeck automatically.

The update still downloads only the canonical GitHub Release Setup asset and verifies its published SHA-256 before launching it.

The Defender-sensitive copied/renamed Picker coordinator used by older releases remains retired. The Setup executable itself owns the update transaction.

Existing settings, history, Automation data, queue state, provider configuration, backups, and other persistent data under %LOCALAPPDATA%\NewzDeck are preserved.

No NNTP connection, SABCTools 9.6.3, SABnzbd 5.1.2, Direct Unpack, post-processing, Automation, Smart Import, Newsgroup Browser, Backup & Restore, or theme behavior is intentionally changed.
