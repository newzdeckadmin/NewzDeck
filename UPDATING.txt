NewzDeck v3.6.77 update notes

Installed users
- Run NewzDeck_v3.6.77_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- You should not need to stop the NewzDeck background service manually; the installer owns the normal upgrade handoff.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.77 Portable ZIP contents, then restart NewzDeck.

v3.6.77 is a UX-only layout/control-consistency release. Runtime behavior, browsing/download performance, Automation, Smart Import, Discover data, Settings persistence, Metadata Server v0.3.3, SABnzbd 5.1.2 and yEnc behavior remain unchanged.
