NewzDeck v3.6.85 update notes

Installed users
- Run NewzDeck_v3.6.85_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- You should not need to stop the NewzDeck background service manually; the installer owns the normal upgrade handoff.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.85 Portable ZIP contents, then restart NewzDeck.

What changes
- Wanted, Library/Calendar and release evaluation now resolve current-file traits through the same canonical helper and evidence precedence.
- Fingerprint-bound release metadata can no longer make Interactive Search disagree with Wanted about whether the current file already contains DV+HDR fallback.
- True Dolby Vision-only files remain upgradeable to Dolby Vision + HDR fallback; already-terminal DV+HDR files no longer remain falsely Wanted.

What stays frozen
- v3.6.84 cutoff-policy semantics, including Allow-versus-Prefer handling and accurate Wanted reason labels.
- v3.6.83 installed/runtime/UI version coherency and same-version update protection.
- v3.6.81 structured Quality Profiles, WEB-DL preference and intended HDR/Dolby Vision progression.
- Newsgroup Browser performance architecture and accepted tuning constants.
- SABnzbd 5.1.2 integration, download queue, post-processing and Smart Import behavior.
- Metadata Server v0.3.3 and Diagnostic Collector v1.0.31.
- Defender-accepted NewzDeckYenc.exe source/build/hash identity and canonical LF/Linux build path.
