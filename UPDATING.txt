NewzDeck v3.6.55
Terminal History Index & Diagnostics Efficiency

INSTALLED NEWZDECK
-------------------
Install the v3.6.55 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

v3.6.55 does not change the private SABnzbd transfer/repair/extraction stack or user-data layout. It optimizes how NewzDeck synchronizes its durable terminal-history index and makes diagnostics distinguish operational state from durable history accurately.

Existing settings, providers, Automation state, durable terminal history, download statistics, queue ownership, user data, and private SABnzbd 5.1.2 are preserved.

Portable users should close NewzDeck and extract the new Portable ZIP to a fresh folder. User data remains outside the application directory.
