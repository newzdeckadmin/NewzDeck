NewzDeck v3.6.61
Newsgroup Browser Progressive Headers & Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.61 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.61 is a narrow newsgroup-browser performance release. It bounds large interactive header first paint, completes deeper All Posts reconstruction in the established background path, and adds passive browsing telemetry. It does not redesign Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation, or Discover.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.61 Portable ZIP to a fresh folder. User data remains outside the application directory.
