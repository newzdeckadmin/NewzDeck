NewzDeck v3.6.88 update notes

Installed build
- Run NewzDeck_v3.6.88_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- The installer is designed to stop/restart NewzDeck-owned runtime components automatically.

Portable build
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.88 Portable ZIP contents, then restart NewzDeck.

No settings reset, library rescan, or cache clearing is required for this hotfix.
