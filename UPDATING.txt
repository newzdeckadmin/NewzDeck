NewzDeck v3.7.0 update notes

v3.7.0 is the production-milestone release built directly on the proven v3.6.99 application baseline.

The normal in-app verified Setup update path is unchanged. Existing NewzDeck settings, history, Automation data, queue state, provider configuration, backups, and other persistent data remain in the normal user-data location and are preserved by a normal update.

There are no intentional user-facing runtime changes from v3.6.99 beyond the 3.7.0 version identity. Settings > Backup & Restore, article-aware TV/Movie sorting, all twelve themes, the Newsgroup Browser, Downloads, Smart Import, Automation, private SABnzbd 5.1.2, and the Defender-clean update/helper architecture are preserved.

The v3.7.0 source also removes an obsolete duplicate GitHub Actions Windows build workflow and refreshes source/build/licensing documentation. These repository-hygiene changes do not alter installed application behavior.
