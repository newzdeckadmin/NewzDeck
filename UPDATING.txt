NewzDeck v3.6.67
Video Thumbnail Concurrency Tuning

INSTALLED NEWZDECK
-------------------
Install the v3.6.67 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.67 is a narrow Newsgroup Browser Video performance release. It raises only the high-connection-provider Video thumbnail scheduler ceiling from four to six while preserving the overall preview/download-reserve budget. It does not change the five-request Image HTTP gate, provider allocation, 24 MB Video sample limit, Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation or Discover.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.67 Portable ZIP to a fresh folder. User data remains outside the application directory.
