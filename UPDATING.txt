NewzDeck v3.7.2 update notes

v3.7.2 is a focused hotfix for v3.7.1. It corrects the download-engine adapter version identity and release-facing metadata while preserving the v3.7.1 SABCTools decoder implementation and download architecture.

Install the v3.7.2 Setup.exe normally over v3.7.1 or an earlier release. Existing settings, history, Automation data, queue state, provider configuration, backups, and other persistent data under %LOCALAPPDATA%\NewzDeck are preserved.

The standalone NewzDeckYenc.exe remains retired. If an older installation still has a stale copy, Setup continues to terminate/delete it during upgrade.

No NNTP connection, article-cache, Direct Unpack, SABnzbd 5.1.2, post-processing, Automation, Smart Import, Newsgroup Browser, Backup & Restore, or theme behavior is intentionally changed by this hotfix.
