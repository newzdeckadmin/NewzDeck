NewzDeck v3.6.19
Non-Disruptive SAB Runtime & Single-Foreground Downloads
Updating

INSTALLED NEWZDECK
------------------
Use NewzDeck > About & Updates > Install Update.

The installer-owned update lifecycle introduced in v3.6.12 remains authoritative:
  1. Capture whether the background service and tray are present/running.
  2. Close the browser-hosted NewzDeck app window from the signed-in Setup session.
  3. Stop the tray and background service.
  4. Replace NewzDeck program files.
  5. Run the newly installed helper as a second app-window-close safety net.
  6. Repair and START the existing background service.
  7. Restore the tray.
  8. Finish Setup and relaunch NewzDeck automatically for /update installs.

v3.6.19 changes private-SAB lifecycle management so transient localhost control
misses do not cause disruptive launch/configuration cycles during active downloads.

Portable users should close NewzDeck and extract the new Portable ZIP to a fresh folder.
Existing settings, provider configuration, Automation data, history, queue state, and
user data remain stored outside the program directory.
