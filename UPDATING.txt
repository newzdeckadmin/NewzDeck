NewzDeck v3.6.64
Name Resolution Result Batching & Thumbnail Transport Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.64 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.64 is a narrow Newsgroup Browser responsiveness/observability release. It batches rapid result-driven filename-resolution renders and adds paired thumbnail transport/concurrency telemetry. It does not redesign Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation, Discover, provider connection budgets, decoder workers, or the proven 800-header strategy.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.64 Portable ZIP to a fresh folder. User data remains outside the application directory.
