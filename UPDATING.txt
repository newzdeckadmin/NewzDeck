NewzDeck v3.6.72 update notes

Installed users
- Run NewzDeck_v3.6.72_Setup.exe over the existing installation.
- The installer handles the running NewzDeck/tray/service upgrade flow; no manual service stop should be required.
- Existing settings, providers, queue state, Automation data, caches and history remain under the version-independent user data directory and are preserved.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.72 Portable ZIP contents, then restart NewzDeck.

v3.6.72 changes only error attribution for browsing/backend transport failures, schema-9 Video policy reason labels, and release identity. Accepted performance and download behavior remains unchanged.
