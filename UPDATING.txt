NewzDeck v3.6.4 updates preserve user state under %LOCALAPPDATA%\NewzDeck.

Installed users should normally run NewzDeck_v3.6.4_Setup.exe over the existing
installation or use the verified in-app updater when offered. Setup preserves the
v3.6.1/v3.6.2 service and tray shutdown protections, so manual service removal or
tray shutdown should not normally be required.

Portable users should close NewzDeck before replacing the application files.
Do not run two different NewzDeck versions against the same per-user data
directory at the same time.
