NewzDeck v3.6.74 update notes

Installed users
- Run NewzDeck_v3.6.74_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- The installer handles the running NewzDeck/tray/service upgrade flow; no manual service stop should be required.
- Existing settings, providers, queue state, Automation data, caches and history remain under the version-independent user data directory and are preserved.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.74 Portable ZIP contents, then restart NewzDeck.

v3.6.74 adds passive schema-11 Video request/session correlation and cancellation-overlap diagnostics only. Accepted browsing/download performance behavior remains unchanged.
