NewzDeck v3.6.65
Thumbnail HTTP Admission Control & Demand Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.65 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.65 is a narrow Newsgroup Browser thumbnail scheduling release. It caps only browser-side image-thumbnail localhost HTTP admission at five requests, adds visible/prefetch admission telemetry, and normalizes expected browsing-session cancellation. It does not reduce provider connections or redesign Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation, Discover, the preview backend, decoder workers, or the proven 800-header strategy.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.65 Portable ZIP to a fresh folder. User data remains outside the application directory.
