NewzDeck v3.6.79 update notes

Installed users
- Run NewzDeck_v3.6.79_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- You should not need to stop the NewzDeck background service manually; the installer owns the normal upgrade handoff.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.79 Portable ZIP contents, then restart NewzDeck.

v3.6.79 is UX Polish Phase 3. Its substantive application change is CSS-only feedback/state polish. Runtime behavior and the v3.6.78 Defender-clean LF/Linux yEnc packaging path remain unchanged.
