NewzDeck v3.6.73 update notes

Installed users
- Run NewzDeck_v3.6.73_Setup.exe over the existing installation after the canonical GitHub release workflow publishes it.
- The installer handles the running NewzDeck/tray/service upgrade flow; no manual service stop should be required.
- Existing settings, providers, queue state, Automation data, caches and history remain under the version-independent user data directory and are preserved.

Portable users
- Close the portable NewzDeck UI/tray, replace the application files with the v3.6.73 Portable ZIP contents, then restart NewzDeck.

v3.6.73 changes only queued thumbnail identity validation, passive schema-10 thumbnail queue visibility telemetry, and release identity. Accepted browsing/download performance behavior remains unchanged.
