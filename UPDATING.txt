NewzDeck v3.6.66
Preview Failure Classification & Video Thumbnail Telemetry

INSTALLED NEWZDECK
-------------------
Install the v3.6.66 Setup EXE normally. Setup owns the service/tray handoff; no manual service stop is required.

Existing settings, providers, Automation library/runtime state, queue ownership, durable Downloads history, statistics and private SABnzbd 5.1.2 state are preserved.

v3.6.66 is a narrow Newsgroup Browser diagnostics/correctness release. It refines known preview failure classes and adds passive Video thumbnail transport/phase telemetry. It does not change the proven v3.6.65 Image HTTP admission gate, provider connection allocation, video concurrency, decoder workers, Metadata Server v0.3.3, SAB transfer/repair/extraction/retry, Smart Import, Automation reconciliation or Discover.

PORTABLE NEWZDECK
-----------------
Close NewzDeck and extract the v3.6.66 Portable ZIP to a fresh folder. User data remains outside the application directory.
